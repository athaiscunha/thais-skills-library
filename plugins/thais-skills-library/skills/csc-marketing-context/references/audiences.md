# Públicos e evidências de público

## Regra central

Construir públicos a partir de documentos, dados de pesquisa fornecidos, linguagem de alunos ou leads com origem rastreável e informações do produto atual. Não inventar personas completas para preencher lacunas.

## Separar evidência de hipótese

Registrar cada elemento como:

- `evidência`: consta em documento, pesquisa, depoimento ou dado fornecido;
- `hipótese`: interpretação estratégica plausível, ainda a testar;
- `restrição`: requisito de elegibilidade, praça, formação ou etapa de decisão;
- `linguagem`: expressão real com fonte rastreável.

Não apresentar paráfrase como fala literal. Não transformar resultado de mídia em atributo permanente do público.

## Estrutura recomendada

Para cada público, organizar somente o que estiver sustentado:

| Campo | Conteúdo |
|---|---|
| Produto e tarefa | O que a pessoa está tentando decidir ou realizar |
| Elegibilidade | Condições formais confirmadas |
| Contexto | Momento profissional, acadêmico ou pessoal sustentado |
| Objeções | Barreiras observadas ou hipóteses identificadas como tal |
| Critérios de decisão | Aspectos comprovadamente relevantes |
| Linguagem | Termos reais e respectivas fontes |
| Fonte e data | Documento, página ou pesquisa |

Consultar o site para verificar se o produto, a modalidade e as condições oferecidas continuam compatíveis com o público descrito.
