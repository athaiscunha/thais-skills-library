# Sistema de editorias

## Distinguir as camadas

- `pilar`: território amplo ligado a objetivo e necessidade do público;
- `editoria`: promessa recorrente que transforma um território em escolha editorial;
- `série`: expressão reconhecível e repetível de uma editoria;
- `formato`: suporte de execução, como Reel, carrossel, foto ou Stories;
- `pauta`: assunto de um episódio;
- `campanha`: esforço coordenado com objetivo e janela.

Não usar “Reels”, “notícias”, “institucional” ou “conteúdo jovem” como editoria sem definir que trabalho recorrente cumprem.

## Registro mínimo

Manter para cada editoria:

| Campo | Decisão |
|---|---|
| nome | como a editoria é reconhecida |
| status | ativa, em teste, pausada, encerrada ou a revisar |
| função | trabalho editorial principal |
| objetivo | mudança de percepção, conhecimento ou ação |
| público | para quem e em qual situação |
| promessa | o que um episódio entrega de modo reconhecível |
| matéria-prima | pessoas, perguntas, fatos, espaços, acervo ou dados |
| invariantes | o que precisa permanecer |
| variações | o que pode mudar sem descaracterizar |
| formatos | principal e alternativas justificadas |
| capacidade | captação, apuração, design, aprovação e prazo |
| riscos | repetição, exposição, direitos, estereótipo ou saturação |
| sinais | evidências fornecidas para manter, ajustar ou pausar |
| episódios | amostra recente, tema e data para evitar duplicação |

Frequência não é identidade. Definir cadência pela disponibilidade de matéria-prima e pela capacidade de criar episódios distintos.

## Auditar o perfil e os documentos

Ao mapear editorias existentes:

1. localizar pelo menos três episódios de cada possível série, quando disponíveis;
2. registrar data, link, pauta, pessoa, formato, abertura, progressão, CTA e matéria-prima;
3. separar rótulo explícito de semelhança percebida;
4. identificar o que permanece e o que varia;
5. verificar se a promessa é distinta de outras editorias;
6. observar repetição, lacunas e custo de produção;
7. validar a leitura com a usuária antes de declarar a definição estável.

Um post isolado não define editoria. Três posts parecidos sem rótulo podem indicar padrão, mas devem permanecer como hipótese até confirmação.

Usar o perfil como evidência de prática editorial e recorrência, não como fonte suficiente para fatos institucionais atuais. Quando o Instagram limitar o histórico público, registrar a data, o período e o tamanho da amostra; complementar com calendário, relatórios, capturas e links fornecidos, sem pedir acesso a conta.

## Criar ou revisar editoria

Exigir:

- vínculo com objetivo e público;
- matéria-prima recorrente real;
- promessa distinta;
- variação suficiente para não esgotar rapidamente;
- produção compatível com a equipe;
- critério para selecionar pautas;
- critério para pausar, mudar ou encerrar.

Não criar nova editoria apenas para organizar visualmente o calendário. Antes, verificar se uma já existente comporta a pauta sem perder clareza.

## Governar episódios

Manter um histórico mínimo de tema, fonte, pessoa, formato e data. Usar esse registro para:

- evitar repetição próxima;
- equilibrar cursos, campi, públicos e tipos de prova sem quotas artificiais;
- planejar captação;
- identificar dependência excessiva de uma pessoa ou formato;
- perceber quando a editoria perdeu a promessa ou virou obrigação.

Encaminhar a execução de cada episódio a `csc-social-content` com a definição vigente e os materiais disponíveis.
